# Security

Please report vulnerabilities privately. Do not open a public issue or PR.

Use GitHub's private reporting: the "Security" tab of this repo, then "Report a vulnerability". Anything that affects
the installer, `get.aidenhq.ai` or a release manifest belongs here. For the kernel or an official module, report it on
[Aiden-HQ/AidenHQ](https://github.com/Aiden-HQ/AidenHQ) the same way.

Include what you found and how to reproduce it. Reports get a reply from the maintainers; fixes ship as a normal PR.
