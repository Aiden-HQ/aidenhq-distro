Questions

What is AidenHQ?

AidenHQ is an open-source Agent OS: the place to build, run and share AI agents. Describe an agent in a sentence and AidenHQ builds it, tries it on real work and adds it to your team, where it works 24/7 alongside agents like Aiden, your chief of staff. Or install agents someone else built. It runs on your own server, with any AI model.

What is an Agent OS?

Everything an agent needs to do real work, built in: its own computer, memory, only the tools you allow, schedules and events that wake it, a team to hand work to, a grader and a second AI that check its work, your approvals, spend caps, and a history you can roll back. You describe the agent; the OS takes care of the rest. No code needed. Agents and teams

Will it send messages without asking?

Not unchecked. Safe, reversible steps run by themselves. Messages, merges and deploys are reviewed by a second AI model first, and anything that speaks for you, spends more or gives an agent more power waits for your one-tap approval. A new install starts quiet: nothing runs on a schedule until you turn it on. How approvals work

Where does my data live?

On the server you run it on. You reach it over HTTPS on your server's own address, behind your password and a one-time code, or keep it on your private network with Tailscale. Every agent, instruction and app lives in your own git repository, so every change can be reviewed and rolled back. Private by design

What does it cost?

AidenHQ is free and open source. You pay for your own server and for the AI models, which OpenRouter bills to your own key. Spend is capped per agent, per task and per day, and the Costs page shows where every cent goes. Spend limits

How do I set it up?

Paste one line into Claude Code, Codex or another coding agent: “Set up AidenHQ on my server by following https://aidenhq.ai/prompt.md”. Or run curl -fsSL https://get.aidenhq.ai | sh yourself on a fresh Ubuntu or Debian server, or a Mac. It ends with a setup link where you create your password and add your model key. Install guide
